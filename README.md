# Clash 小岛（clash-verge-island）

把本机 **Clash Verge** 的状态搬到 **WinIsland 灵动岛**上。

- **小岛**：当前节点 + 延迟（延迟按绿 / 黄 / 红着色）
- **展开**：当前模式、实时上下行网速、分组名、内核版本
- **点击岛体**：弹出聚光卡 —— 切节点、切模式（规则 / 全局 / 直连）、一键测速
- **设置页**：地址、端口、Core Secret、「保存并测试连接」

## 用之前必须先做一步

Clash Verge Rev 从 **v2.4.0** 起**默认关闭**了对外接口，所以插件默认是连不上的（表现为「连不上」而不是「密码错」）。

打开方法：

1. 打开 Clash Verge → **设置** → 「**Clash 设置**」
2. 找到 **External** 那一行，点开
3. 打开「**Enable External Controller**」
4. 地址填 `127.0.0.1:9097`
5. **Core Secret** 设一个密码（默认值 `set-your-secret` 谁都能猜到，建议改掉）
6. 保存（内核会重启一下）
7. 回到灵动岛的插件设置页，把**端口**和**Core Secret**填成一样的，点「保存并测试连接」

## 数据从哪来

全部来自 Clash Verge 自带的 mihomo 内核本地接口，**不出本机**：

| 用途 | 接口 |
|---|---|
| 连通性 / 版本 | `GET /version` |
| 当前模式 | `GET /configs` |
| 网速（累计字节数差分） | `GET /connections` |
| 节点、分组、延迟 | `GET /proxies` |
| 切换节点 | `PUT /proxies/{分组}` |
| 切换模式 | `PATCH /configs` |
| 整组测速 | `GET /group/{分组}/delay` |

认证方式：`Authorization: Bearer <Core Secret>`。

## 说明

- **国旗**：Windows 系统字体里没有国旗图案（打 `🇯🇵` 只会显示成「JP」两个字母），
  所以插件自带 82 面小国旗 PNG（`flags/<代码>.png`，来自 [flagcdn](https://flagcdn.com)，
  基于 MIT 许可的 flag-icons 项目，约 18 KB）。认不出地区时退回地球图标；
  认得出地区但缺对应图时，退回「国家色 + 两个字母」的徽章。
- 策略组列表比较大，插件每 3 次刷新（约 6 秒）才拉一次；网速和模式每 2 秒更新。
- 网速做过指数平滑：原始值是每 2 秒一次的瞬时差值，直接显示会疯狂跳动、根本读不清。
- 测速优先用**策略组自己配置的测速地址**，让延迟数值和 Clash Verge 界面里看到的一致。
- 请求绕开了系统代理（`UseProxy = false`）—— 访问 127.0.0.1 没必要走代理，否则可能被规则绕进去。
- 本插件与 Clash Verge 官方无关，只是读取它开放的本地接口。
